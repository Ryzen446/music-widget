Music Widget · Liquid Glass for Windows
Project: https://github.com/Ryzen446/music-widget

ENGLISH
Open Music Widget from the Start menu after installing MusicWidget-Setup.exe.
For the portable ZIP, extract all files to a folder you can write to, then
open MusicWidget.exe.

Use the three-dot menu and select Add music → Link or file to import audio.

Press Ctrl+Shift+M to show or hide the player. Right-click the Music Widget
icon by the Windows clock to open the music folder, enable startup or quit.

Music Widget uses the native Windows WPF interface and .NET Framework 4.8.
The installer checks for the framework before continuing.

Choose Enable online tools on the Add music page to set up search, previews
and downloads. Local audio and playlists are ready immediately.

FRANÇAIS
Après l’installation de MusicWidget-Setup.exe, ouvre Music Widget depuis le
menu Démarrer. Pour le ZIP portable, décompresse tous les fichiers dans un
dossier où tu peux écrire, puis ouvre MusicWidget.exe.

Dans le menu à trois points, choisis Ajouter de la musique → Lien ou fichier.

Ctrl+Maj+M affiche ou masque le lecteur. Un clic droit sur l’icône près de
l’horloge permet d’ouvrir le dossier musique, de régler le démarrage ou de quitter.

Music Widget utilise l’interface native Windows WPF et .NET Framework 4.8.
L’installateur vérifie la présence de .NET Framework avant de continuer.

Pour configurer la recherche, l’écoute en ligne et les téléchargements,
choisis Activer les outils en ligne dans Ajouter de la musique.
La lecture et les playlists locales fonctionnent dès le premier lancement.
